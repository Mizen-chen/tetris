## 🕹️ 游戏规则

1. **基本玩法**：
    - 游戏区域为 10 列 × 20 行的网格。
    - 7 种不同形状的方块会从顶部不断下落。
    - 玩家通过控制方块的移动和旋转，使其填满水平方向的整行。
2. **消除与得分机制**：
    - **基础得分**：每成功固定（落地）一个方块，基础分数 `+1`。
    - **消行奖励**：当某一行被方块填满时，该行消失，上方方块整体下移。每消除 1 行，额外获得 `100 × 当前等级` 的奖励分。
3. **等级与难度**：
    - 游戏初始等级为 1 级。
    - 每累计消除 5 行，等级提升 1 级。
    - **难度递增**：等级越高，方块自动下落的速度越快。
4. **游戏结束**：
    - 当新生成的方块在顶部无法放下（与已有方块重叠）时，游戏结束。
    - 结束后分数会自动存入数据库，并触发广播返回主界面。

## 🎮 按键操作说明

### 顶部功能栏
| 按键 | 功能说明 |
| :--- | :--- |
| 🏆 **查看排行榜** | 自动暂停当前游戏，跳转至排行榜页面查看历史最高分。 |
| 🚪 **返回主页** | 暂停游戏并结束当前对局，返回登录主页。 |

### 底部控制栏
| 按键 | 功能说明 |
| :--- | :--- |
| ⬅️ **向左** | 控制正在下落的方块向左移动一格。 |
| 🔄 **旋转** | 控制方块顺时针旋转 90 度（若边缘碰撞会自动回退）。 |
| ➡️ **向右** | 控制正在下落的方块向右移动一格。 |
| ⬇️ **速降** | 方块瞬间垂直下落到最底部并固定。 |
| ⏸️ **暂停** | 暂停或继续游戏（防止切屏时游戏继续下落）。 |

## 🛠️ 核心技术点实现（对应大作业要求）

本项目完美覆盖了大作业的所有硬性技术要求：

| 技术组件 | 对应类 / 文件 | 功能说明 |
| :--- | :--- | :--- |
| **Activity** | `MainActivity`<br>`GameActivity`<br>`RankActivity` | 负责 UI 展示与页面跳转（主页、游戏页、排行榜页）。 |
| **Service** | `GameService` | **绑定式 Service**。负责核心游戏逻辑（计时、方块下落、碰撞检测），使游戏逻辑与 UI 界面彻底分离。 |
| **BroadcastReceiver** | `BootReceiver` (静态)<br>`GameActivity` 内部类 (动态) | 动态注册接收游戏结束广播，触发分数保存；静态注册接收开机广播。 |
| **ContentProvider** | `ScoreProvider` | 对外暴露 `player` 和 `score` 数据的 URI，所有数据读写均通过 `ContentResolver` 完成。 |
| **SQLite 数据库** | `DBHelper` | 建立本地 `tetris.db` 数据库，包含 `player`（玩家表）和 `score`（分数表）。 |
| **Intent** | 全局 | 页面传值（如传递玩家昵称）、启动 Service、发送广播。 |
